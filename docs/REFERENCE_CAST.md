# Reference Cast

BRIDGE is role-based and product-agnostic. This document preserves the reference casting from the project in which the operating model was developed so that a future user can recreate that exact setup without confusing it for a hard dependency.

| BRIDGE role | Reference assignment | Function |
|---|---|---|
| Owner | Karma | Owns objectives, priorities, risk tolerance, and final consequential authority. |
| Architect | Hex / ChatGPT | Maintains the map, decomposes work, reconciles evidence, adjudicates gates, and keeps the project coherent. |
| Primary Builder | Codex | Executes one bounded substantive operation at a time with implementation freedom inside the authorized box. |
| Stand-in Builder | Claude Code | May replace the Primary Builder for a bounded operation; inherits Builder authority and restrictions. |
| Independent Verifier | Fable | Independently attempts to falsify material claims; does not repair the artifact it verifies. |

## Independence invariant

The names above are replaceable. The structural rule is not.

A Verifier must be independent of the substantive Builder for the artifact under review. An agent cannot create independence merely by opening a new chat or changing its prompt after building the artifact.

## Owner is not middleware

The Owner is a decision-maker, not a shell proxy, evidence courier, or message bus when an authorized agent can perform the work directly.
