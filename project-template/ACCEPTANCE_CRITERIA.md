# Acceptance Criteria

Define criteria **before** inspecting outcome data that could bias the standard.

Separate:

## Project-level criteria

What must be true before the project objective can be called complete?

## Gate-level criteria

What must be true to cross the current major gates?

## Evidence standard

What evidence is sufficient for each criterion?

## Independent review requirement

Which gates require independent Verifier review before Architect closure?

## Stop conditions

Which findings fail closed or require Owner escalation?

Keep criteria observable and proportionate. Avoid ceremonial requirements that do not control a real risk.
