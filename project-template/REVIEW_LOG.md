# Review Log

Use stable finding IDs.

| Finding ID | Area | Severity | Status | Raised by | Independently verified by | Exact evidence | Required falsification / acceptance | Implementation identity | Remaining limitation |
|---|---|---|---|---|---|---|---|---|---|

Recommended statuses:

- `OPEN`
- `PENDING INDEPENDENT VERIFICATION`
- `FIXED`
- `REJECTED`
- `NEEDS EXTERNAL EVIDENCE`
- `DEFERRED`

Do not mark a finding fixed from a PR description or Builder assertion alone when the project requires independent evidence.
