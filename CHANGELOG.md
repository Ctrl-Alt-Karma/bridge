## 1.0.0 — 2026-08-11

Initial public BRIDGE release, distilled from a multi-agent operating model developed through sustained governed technical work.

Codifies:

- Owner / Architect / Builder / Verifier separation;
- one active Architect cockpit;
- one active Builder at a time;
- Codex primary Builder with Claude Code stand-in;
- Fable independent adversarial verification and no self-repair;
- bounded-objective Builder freedom;
- first-output runtime estimate rule without post-hoc scoring;
- Builder PASS versus Architect adjudication;
- granular write, merge, submission, deployment, and destructive-action authority;
- proportional evidence reacquisition;
- clean handoffs and cold-start comprehension handshakes;
- strict separation between reusable governance and project-specific domain rules.
